# CampusX

A modern, full-stack project management and collaboration platform built with **Next.js 15**, **React 19**, and **Tailwind CSS 4**. CampusX empowers students, developers, and professionals to browse, manage, and showcase projects, connect with experts, and accelerate their learning and career growth.

![CampusX Banner](public/project.jpg)

---

## 🚀 Features

- **Project Library:** Browse, search, and filter a curated collection of top-notch projects to enhance your resume.
- **Expert & Developer Connect:** Hire academic experts or professional developers for guidance or collaboration.
- **Modern UI Kit:** Built with a custom component library and Radix UI primitives for a beautiful, accessible experience.
- **Testimonials:** Real user stories to inspire and build trust.
- **Responsive Design:** Fully responsive and mobile-friendly layouts.
- **Fast & Scalable:** Powered by Next.js 15 and optimized with Tailwind CSS 4.

---

## 🗂️ Project Structure

```
app/
  projects/
    project-library/   # Project Library feature
  dashboard/           # User dashboard
  marketplace/         # Project marketplace
  rentals/             # Rentals feature
components/
  ui/                  # Reusable UI components (Button, Card, Tabs, etc.)
custom-components/     # Custom feature components (Headline, Footer, etc.)
data/                  # Demo data for projects, marketplace, dashboard, etc.
```

## 🛠️ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/)
- **UI:** [React 19](https://react.dev/), [Tailwind CSS 4](https://tailwindcss.com/)
- **Component Primitives:** [Radix UI](https://www.radix-ui.com/)
- **Icons:** [Lucide React](https://lucide.dev/icons/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/)

## 🏁 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

3. **Open your browser:**
   Visit [http://localhost:3000](http://localhost:3000) to see CampusX in action.
